# Website quy trình mượn - trả sách thư viện (A3 - FIT4014)

Website tĩnh HTML5/CSS3 mô tả quy trình mượn - trả sách theo 6 bước.
Quy trình là mô hình minh họa do sinh viên xây dựng, không phải quy định chính thức của thư viện nào.

## Cấu trúc thư mục
```
index.html       Trang chủ
quy-trinh.html   Quy trình 6 bước, 3 trường hợp khi trả sách, bảng vai trò
quy-dinh.html    Bảng quy định, checklist, câu hỏi thường gặp
css/style.css    File CSS riêng style.css
README.md  AI_LOG.md
```

## Cách mở
Mở `index.html` bằng trình duyệt. Không cần cài đặt gì.

## Đưa lên GitHub Pages
1. Tạo repository, đẩy toàn bộ file lên nhánh `main`.
2. Settings -> Pages -> chọn nhánh `main`, thư mục `/ (root)`.
3. Mở URL GitHub Pages và đối chiếu với commit đã nộp.

URL: (điền sau khi triển khai)   Commit/tag: (điền)

## Giới hạn đã biết
- Chưa kiểm tra trên Firefox, Safari, thiết bị thật; chưa chạy W3C Validator hay Lighthouse.
- Chưa đo độ tương phản màu bằng công cụ.
- Số liệu quy định là giả định minh họa.
